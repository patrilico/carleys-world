# Carley's World

A cosy browser game: keep Carley happy by telling her what to do. Her meters (Rest, Fun, Social, Relax, Garden, Tummy)
drain slowly and only fill while she does something for them.

## Run locally
    npm install
    npm run dev

## Tests / build
    npm test
    npm run build      # output goes to dist/

## Deploy on Render (Static Site)
- Build command: `npm install && npm run build`
- Publish directory: `dist`
